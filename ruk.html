Memuat daftar berkas...

Klik nama berkas atau folder untuk membukanya di Google Drive. Daftar ini mengikuti isi folder saat data disinkronkan ulang (python tools/sync.py).

Cara membaca & memperbaiki data
  • Setiap panel mencantumkan sumber data di bagian bawah kartu: nama berkas Excel-nya beserta folder tempat berkas itu berada di Google Drive.
  • Kalau angka di halaman berbeda dengan dugaan Anda, buka berkas Excel pada folder itu (tombol Buka folder Drive di atas) dan cocokkan kolomnya.
  • Sesudah berkas diperbaiki di Drive, tekan Sinkronkan data di kanan atas agar halaman menampilkan angka terbaru.
  • Format berkas yang dipakai dashboard dijelaskan di README pada bagian "Saran perbaikan data".
